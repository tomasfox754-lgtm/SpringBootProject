# LogiTrack frontend

Frontend basico para el proyecto Spring Boot de LogiTrack, realizado con HTML, CSS y JavaScript sin frameworks. Colores neutros, formularios sencillos y conexion con los endpoints que ya probamos en Swagger.

Cuenta ADMIN: CRUD de bodegas y productos, movimientos, reportes y auditorias.
Cuenta EMPLEADO: consulta de catalogos, movimientos y reportes.

Los roles se administran en el backend. No se leen del JWT.
